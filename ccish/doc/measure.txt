its order: a 12-byte header (the same in every image), Names (the
dependencies' and imports'), Table (the function table, 2 bytes a function,
init too), Data, Code and Fixups. Not in the file: (Zero), the zero region,
the disk space saved, shown where it goes in memory, after Data (init
clears it); (REL), the same program as a REL module, for comparison. XLOAD
is a REL module, and XLOAD2, its second part, an image.
